# Test-medicament

- `index.html` : suivi de prise de médicament (calendrier, prochaines prises, série de prises respectées).
- `scan.html` : webapp mobile pour photographier des écrits (brouillons, croquis...) et les faire remettre au propre par l'IA. Nécessite une clé API Anthropic (renseignée dans les réglages ⚙️, stockée uniquement sur l'appareil).
